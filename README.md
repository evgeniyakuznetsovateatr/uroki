# Уроки актерского мастерства для взрослых — Яблоновский

Одностраничный сайт занятий Евгении Кузнецовой: о педагоге, навыки, программа курса,
расписание, цены, пробное занятие, частые вопросы и контакты.

## Структура

- `index.html` — весь сайт: разметка, стили и небольшой скрипт кнопки «Скопировать номер».
- `assets/evgenia.jpg` — фото педагога.

Внешние зависимости — только шрифты Google Fonts (Playfair Display и Manrope).
Сборка не нужна: достаточно открыть `index.html` в браузере.
